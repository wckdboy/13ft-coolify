    How this works
    • Googlebot identity. The server requests the page with a crawler user-agent, so it gets the fully rendered article that search engines index.
    • Fallback chain. If the site serves an anti-bot challenge, 13ft tries Freedium (Medium), archive.org and archive.today before giving up.
    • Cleanup. Ads, overlays, frame-busting scripts and tracker scaffolding are stripped before the page reaches you.
    • Nothing is stored. Rendered pages live in server memory for about five minutes; your link history below stays in this browser only.

    If you read something worth keeping, subscribe to the publication. This is for the one-off article, not for replacing the people who wrote it.
